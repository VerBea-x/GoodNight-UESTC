四步完成签到计划

下方为界面示意。每一步都能在“签到计划”页完成。

01 / 账号

添加账号并完成学校登录

点击“添加打卡账号”，保存后点“学校登录”。在新窗口完成统一认证，并进入“晚安成电”；回到工作台点“我已登录，验证状态”。

02 / 位置

在地图上选择签到位置

编辑账号，选择“虚拟位置 · 仅签到”，再点“地图选点”。点击地图或拖动标记，使用位置后还要点“保存配置”。也可以读取学校返回的可用签到点。

推荐百度地图：首次使用需在 百度地图开放平台申请免费浏览器端 AK，并把 127.0.0.1 加入 Referer 白名单。没有 AK 可选 OpenStreetMap 备用地图。点位统一转换为 GCJ-02；只有位于学校当前有效范围内的位置才能尝试签到。

03 / 时间

设置时间，先做只读检查

填写北京时间的开始与截止时间，例如 21:00–23:00。保存后执行“读取今日记录”和“试运行”，检查学校登录、开放时段和所选位置。

这两项检查不会提交签到。

04 / 运行

开启计划并核对结果

点击“开启自动计划”。电脑保持开机、联网且登录状态有效，后台会在设定时段内尝试运行。之后在“运行记录”查看结果，并到学校页面核对最终记录。

“需要重新登录”或“位置检查未通过”时，按提示处理后再检查。

INSTALL

选择你的设备

▣

电脑本机工作台

Windows：把项目放在固定目录，双击 install-web.cmd，随后在浏览器打开 127.0.0.1:3210。安装成功后无需保留终端窗口，登录电脑时后台自动启动。

需要 Node.js 22 或更新版本，以及 Chrome 或 Edge。电脑必须保持开机、联网。

▯

安卓手机独立版

安装项目中的 APK，先在电脑端账号的“检查与管理”复制手机配置，把文字传到手机并在应用里粘贴导入；然后在手机只读检查登录状态、开启计划。到设定时段自动尝试，收到通知后核对；失败时可在有效时段手动使用保存的位置签到。

手机独立运行，不修改系统定位。手机端不再使用地图；复制的配置只含位置和时间，不含学校登录凭据；手机已有的有效会话可继续使用。后台任务可能因省电策略延迟。

CHECK THE RESULT

看到这些状态时

已确认成功

学校当天记录已确认。可在学校页面再次核对。

需要重新登录

认证已过期；重新打开学校登录，再验证状态。

位置检查未通过

重新读取学校可用签到点，核对所选位置和半径。

结果待核对

程序不会因为结果不明就盲目重复提交；请读取今日记录。

虚拟位置模式只尝试签到，不自动转为报告。手动“立即执行”会提交真实请求；只读检查和试运行不会提交。
