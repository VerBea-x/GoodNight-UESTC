# 本机网页控制台

每位同学在自己的电脑部署并打开网页。无需注册额外的网站账号，学校认证在本机浏览器完成，配置及登录数据只保存在本机用户数据目录。此版本只监听 `127.0.0.1`，不提供公网多人账号平台。

本项目基于 [GoodNight 源项目](https://github.com/beichenO2/GoodNight) 增加本机网页界面、地图选点和独立账号配置。网页只保留“签到计划”和“运行记录”两个操作页；“使用指南”用四幅界面示意图说明登录、选点、检查与自动运行。地图点选体验参考 [GoGoGo](https://github.com/ZCShou/GoGoGo)，没有复制其 Android 代码。

## 启动

安装 Node.js 22 或更新版本及 Chrome / Edge，下载仓库后：

**Windows 最简单的后台部署：**将项目解压到固定目录，双击 `install-web.cmd`。脚本会安装依赖、注册当前用户的登录启动任务并打开网页。以后每次登录 Windows 后服务会自动启动。安装后请勿移动或删除项目目录；电脑须开机、联网。

如果只想临时运行，双击 `start-web.cmd`，并保持打开的命令窗口。也可在终端手动运行：

```sh
npm ci
npm run web
```

打开终端打印的 `http://127.0.0.1:3210`。无需先执行 `init`。macOS/Linux 可执行 `sh start-web.sh`。

## 配置流程

1. 在“打卡账号”添加账号，填写名称、浏览器和每天的开始/截止时间。
2. 点击“学校登录”，在新打开的浏览器中完成统一认证及验证码，再点击学校的“晚安成电”。回到网页点击“我已登录，验证状态”。
3. 编辑账号，选择“虚拟位置 · 仅签到”，点击“地图选点”，在地图上单击或拖动标记并命名，点“使用此位置”。也可点击“读取学校可用签到点”，选择学校返回的地点，或手动填写 GCJ-02 经纬度。地图选点会把 WGS-84 转为学校使用的 GCJ-02。虚拟位置模式只尝试签到，不自动提交报告。
4. 点击“读取今日记录”和“试运行”。试运行不提交签到或报告，但需要在学校开放时段内才能完成准备检查。
5. 配置确认后，开启账号右上角的自动计划。新账号默认不开启。

账号卡片的“检查与管理”可展开只读检查、试运行、立即执行和删除。删除会先停止该账号的自动计划：网页新建账号的数据移动到本机数据目录的 `archived-accounts/`，便于手动恢复；原 CLI 导入的账号仅从网页列表移除，原 CLI 数据保留。删除前需在网页确认。

开始/截止时间都使用北京时间。学校时段与用户时间共同限制执行，截止时间不晚于 23:55。网页调度每 30 秒检查账号，按日记录结果并复用现有提交日志及防重复逻辑；保存配置后会在下一次调度检查读取新值。关闭计划不取消已经发送的请求。

新账号使用独立的配置目录和浏览器 profile；已有 CLI 默认配置会显示为“我的账号”，直接复用原配置与登录状态，不复制 Cookie，导入时默认不开启网页自动计划。切换到网页后台前应停用原来的单账号 daemon，避免两套调度争用浏览器。

## 后台运行

关闭网页标签页不会停止服务；关闭启动终端会停止前台服务。安装为当前用户服务可在用户登录电脑后运行：

```sh
node bin/goodnight.mjs service install --web
```

此命令替换同名的原 CLI daemon 服务。已有服务在替换前应先停止，避免旧进程继续运行。Windows 可在任务计划程序结束任务 `io.github.beichenO2.goodnight`；macOS/Linux 可先执行 `service remove` 再安装网页服务。

自定义端口：

```sh
node bin/goodnight.mjs web --port 3211
node bin/goodnight.mjs service install --web --port 3211
```

电脑需要开机、联网并保持可用的用户桌面会话。登录过期后在网页中重新登录。设备定位模式依赖真实系统定位；虚拟坐标替换并不保证学校服务接受。

## 地图服务与坐标

网页选点支持百度地图 JavaScript API 3.0 与 OpenStreetMap 备用地图。百度地图在国内通常加载更快，但需要每位同学自行在[百度地图开放平台](https://lbsyun.baidu.com/docs/jsapi?title=jspopular3.0%2Fguide%2Fgetkey)申请免费的“浏览器端 AK”，启用 JavaScript API，并将 `127.0.0.1` 加入 Referer 白名单。第一次在“地图选点”弹窗填写 AK 并点击“加载地图”；AK 只保存在当前浏览器的本地存储中，网页向百度地图加载脚本时会发送该 AK。之后默认使用百度地图；没有 AK 时默认使用 OpenStreetMap。百度地图显示 BD-09 坐标，选点后在浏览器内转为学校提交的 GCJ-02。

OpenStreetMap 备用地图使用本地安装的 Leaflet 和 coordtransform，无需密钥。地图仅在打开弹窗后加载，按照[瓦片使用政策](https://operations.osmfoundation.org/policies/tiles/)显示版权标注、传送 Referer、遵守浏览器缓存，不提供批量下载。服务可能限流或无法访问；此时可使用百度地图、学校签到点列表或手动 GCJ-02 坐标。地图提供者会收到常规网页请求和查看区域。GoGoGo 的代码没有并入本项目。

选择地图点位只会更新编辑表单；只有点击“保存配置”才会写入账号，开启计划后才会按时运行。选中的地图点不保证符合学校返回的签到范围。

## 数据与本机访问边界

网页账号索引在默认数据目录的 `web-accounts.json`，新增账号配置、profile、日志在 `accounts/<随机ID>/`。原 CLI 账号仍使用原数据目录。所有这些文件都在仓库外，请勿随源码分享。

Windows 上，应用管理的 JSON 配置、账号索引、运行状态及日志会用当前用户的 DPAPI 密钥和 AES-256-GCM 加密；旧文件在首次打开相应数据目录时迁移。浏览器 profile 由 Chromium 与 Windows 自身管理，应用不会替浏览器加密所有缓存或本地存储。不要删除数据目录内的 `.goodnight-key`；如需覆盖全部离线数据，建议开启 Windows 设备加密或 BitLocker。

API 校验 Host、Origin 和每次服务启动生成的请求令牌，限制跨站修改；没有开放跨域访问。它是个人电脑的本机控制台，无法阻止已在同一电脑上运行的恶意程序读取用户文件，不能作为公网服务直接暴露。

源码包含离线 API 与隔离测试。真实系统服务、学校认证、定位和提交是否可用仍需按部署设备验证；Windows 本机已测试的行为以实际运行记录为准。
