# Android 使用指南

Android 应用独立运行，不依赖电脑后台。它在应用内的学校页面完成登录，使用保存的 GCJ-02 坐标与时段安排签到，并在结果可用时提醒核对。它不改变系统定位，也不会影响其他应用的位置。

## 配置

从[本仓库 Releases](https://github.com/VerBea-x/GoodNight-UESTC/releases)选择版本，下载 Assets 中的 APK。最低 Android 8.0（API 26）；Source code 压缩包不是安装包。升级前核对版本与签名，建议覆盖安装并保留数据。排查见[常见问题](faq.md)。

1. 在电脑端打开账号的“检查与管理”，复制手机配置；在手机首页点“粘贴配置”。复制的文字包含坐标与时段，不含学校密码或 Cookie。也可直接填写经纬度。
2. 点“学校登录”，在学校页面完成认证并进入“晚安成电”。如果学校页面自动进入，说明浏览器会话可能仍有效；以应用内状态和学校记录为准。手机浏览器的会话不会自动共享给本应用的 WebView。
3. 核对“签到坐标”和“签到时间”，打开“自动签到”开关。关闭开关会取消计划；重新打开会重新注册后台任务。
4. 从顶部进入“签到记录”查看结果。自动运行后，应用会尝试读取当天学校记录并通知核对；登录失效时请重新登录。

手机端不提供地图选点。电脑端地图支持百度地图（需要自行申请浏览器端 AK）和备用图层，选好后将配置复制到手机即可。虚拟坐标只用于本应用请求；学校可能拒绝该坐标，配置不保证成功。

## 后台执行

v0.6.6 将状态读取、开关保存和任务注册放到后台线程。点击后顶部立即显示正在开启或关闭，保存完成后显示确认状态；开关持续可操作，连续点击按最后一次选择更新。失败时关闭计划并提示重试。请覆盖安装新版 APK，以保留原有加密数据。

Android 使用 JobScheduler 在配置时段内调度联网任务。系统可能因省电、网络或后台限制推迟任务，无法承诺准点。手机需要开机、联网并保持学校登录有效；建议允许应用通知，收到提醒后查看学校官方记录。当天已处理的结果不会因反复开关而盲目重复提交。

v0.6.2 补上 `ACCESS_NETWORK_STATE` 权限，修复关闭后再开启计划时系统拒绝注册联网任务的问题。v0.6.3 将设置与记录迁移到 Android Keystore 加密的偏好数据，并在应用内显示本项目免责声明。v0.6.4 的“清除”按钮会删除全部本机签到历史，包括当天；学校记录不会删除。自动保留阈值仍不清理当天记录。记录页的只读刷新不再生成新历史。

自动任务完成一次尝试后会通过“签到结果”通知渠道发出提醒，等待学校开放的状态不会反复提醒。Android 13 及以上需要授予通知权限，系统或用户关闭通知时，首页会显示通知状态；未授权不会影响签到任务本身。请覆盖安装，不要先卸载。WebView 登录会话由 Android 的应用沙箱和设备加密保护，不在应用偏好加密范围内。

## 安装与构建

可安装项目发布的 APK，或在 Windows 上运行仓库根目录的 `build-android.cmd` 自行生成 `dist/GoodNight-Android-debug.apk`。源码构建需要 JDK 17、Android SDK Platform 35、Build Tools 35.0.0、Gradle 8.13。生成 APK 只证明构建成功，实际后台唤醒、学校登录和签到结果应在手机上核验。
