# Android 使用指南

手机端独立运行，支持 Android 8.0 及以上。它使用保存的坐标发送签到请求，不修改系统定位。

## 1. 安装

打开 [Release 下载页](https://github.com/VerBea-x/GoodNight-UESTC/releases/tag/v0.6.6)，下载附件中的 APK。Source code 压缩包是源码，不能直接安装。

升级时覆盖安装即可。若提示签名不兼容，请保留旧应用并反馈，不要直接卸载。

## 2. 登录学校

点击“学校登录”，完成学校认证，再进入“晚安成电”，然后返回应用。

如果页面自动进入，可能已有有效会话。其他手机浏览器的登录状态不会自动共享给本应用。

## 3. 设置位置和时间

在电脑端账号的“检查与管理”中复制手机配置，传到手机后点击“粘贴配置”。也可直接填写 GCJ-02 经纬度。

核对开始、截止时间，再打开“自动签到”。顶部会先显示正在开启，保存完成后显示计划已开启。连续点击以最后一次选择为准；失败时会关闭计划并提示重试。

手机端没有地图。需要选点时，在电脑端完成后复制配置即可。配置文字不含学校密码或 Cookie。

## 4. 查看结果

允许通知，并检查系统是否限制应用后台运行。Android 13 及以上需要单独授予通知权限。

自动任务完成尝试后会发送“签到结果”通知。等待学校开放时不会反复提醒。手机需要开机、联网并保持学校登录有效；系统省电可能推迟任务。

从顶部打开“签到记录”查看本机运行结果，再到学校页面核对当天记录。没有通知不等于没有运行，通知到达也不代表学校已确认签到。

## 记录与数据

“清除”会删除全部本机历史，包括当天；学校记录和当天提交保护仍保留。自动清理保留当天记录，只读刷新不会生成新历史。

设置和运行记录使用 Android Keystore 加密；WebView 登录资料由 Android 管理。卸载可能丢失设置、密钥和登录状态。

## 从源码构建

需要 JDK 17、Android SDK Platform 35、Build Tools 35.0.0 和 Gradle 8.13。设置 JAVA_HOME、ANDROID_HOME，在 Windows 运行项目根目录的 `build-android.cmd`。

生成文件：`dist/GoodNight-Android-debug.apk`。这是调试签名包，跨机器重新构建可能无法覆盖原安装；发布前阅读[签名说明](releases.md)。
