# Source audit

Audit date: 2026-10-12 (Asia/Shanghai), with a location-contract correction. These are engineering claims. Static frontend code establishes the client contract, not server acceptance or live platform compatibility. Incident outcome details are maintainer-provided and private evidence is excluded; no private browser data, school records, logs, coordinates, or personal report text are included.

| Claim | Verdict and evidence | Remaining limit |
| --- | --- | --- |
| Manual login uses an isolated persistent browser profile; ordinary browser login is separate | **CONFIRMED**: `bin/goodnight.mjs` login flow and `src/browser.mjs`; [Playwright persistent context](https://playwright.dev/docs/api/class-browsertype#browser-type-launch-persistent-context) | A real user must complete authentication; server expiry is unknown |
| Location first calls `uni.getLocation`, otherwise discovers the current frontend binding from source | **CONFIRMED** in `src/location.mjs` and `src/frontend-contract.mjs`: Acorn parses the same-origin entry and student chunk; it resolves the named import used in a direct `{ type: 'gcj02', success, fail }` call and verifies the entry export. Acorn is a JavaScript parser ([official README](https://github.com/acornjs/acorn/blob/master/README.md)). Unauthenticated GET + the repository resolver at audit time confirmed [entry bundle](https://jzsz.uestc.edu.cn/daily-checkin-h5/assets/index-CqZyvL8l.js) exports `bl`; [student bundle](https://jzsz.uestc.edu.cn/daily-checkin-h5/assets/pages-student-report-today-home-index.Bdf9noCE.js) imports `bl` as `W` and calls `W` with the GCJ-02 callbacks | Bundle URLs are current snapshots and may change; code fails closed if ambiguous or absent. Coordinate system is requested, not independently measured |
| Endpoint names, report/check-in bodies and dorm circles follow the observed client | **CONFIRMED** static contract: [current student API module](https://jzsz.uestc.edu.cn/daily-checkin-h5/assets/student.EY75qyhw.js) lists endpoints; student page sends latitude/longitude/reverseGeocode/clientTime/userAgent for check-in, and gpsAccuracyMeter/coordinateSystemCode for report; reads radiusMeter circles | Live acceptance of the new adapter remains **UNVERIFIABLE** from static code alone. Diagnostic fields beyond known accuracy are omitted |
| Unknown POST outcomes cannot repeat or authorize fallback | **CONFIRMED** `src/runner.mjs`, `src/store.mjs`, `test/core.test.mjs`: per-operation atomic claim precedes POST; unknown outcome only reconciles. Other codes stop without fallback |
| Check-in and report saved-record verification differ | **CONFIRMED** `src/policy.mjs` and runner tests: check-in requires date + CHECKED_IN; report requires date + STUDENT_REPORTED + type + keyword + exact remark. Current active option is resolved dynamically before submission; no claim that this default was live-submitted by the new port |
