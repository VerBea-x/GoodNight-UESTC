# 项目结构

- android/：独立 Android 应用，学校登录、配置、定时任务、通知与签到记录。
- desktop/：Windows 桌面启动程序。
- web/：本机控制台与使用指南。
- src/：电脑端配置、浏览器适配、调度、状态存储与学校接口处理。
- bin/：命令行入口。
- test/：离线测试；不会向学校提交考勤。
- docs/：当前安装、使用与发布文档。

电脑端通过独立浏览器配置保存学校会话，网页只监听本机。Android 端使用自己的 WebView 会话和系统 JobScheduler，不依赖电脑持续运行。

应用提交前保存当天提交保护，结果不明时回读学校记录；清除显示历史不会删除提交保护。配置与应用记录的加密范围见 README。学校保存的签到结果是最终结果。
