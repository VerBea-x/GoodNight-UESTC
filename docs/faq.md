# 常见问题

## 下载哪个文件？

手机安装 Releases 的 APK。Source code 是源码；PC 用户下载已有的 Windows 发布包或按 docs/pc.md 自行构建。main 上的源码版本可能比 Latest 的安装包新，先核对 Release 标签。

## 手机需要电脑一直运行吗？

不需要。手机独立保存登录、坐标和计划。电脑只在选点或复制配置时使用。手机保持开机联网，学校会话有效，并允许应用后台运行。

## 为什么开关先显示“正在开启”？

这是本机保存和任务注册中的状态。开关动画先响应，后台完成后显示确认状态；连续点击以最后一次选择为准。如果失败，计划会关闭并提示重试。它不代表已经向学校提交签到。

## 没收到通知怎么办？

检查系统对本应用的通知权限及“签到结果”通知渠道。Android 13 及以上需要授权通知。学校尚未开放时的等待状态不会反复通知；后台被系统限制也可能使任务延迟。查看签到记录和学校实际结果，不要只凭有没有通知判断成功。

## 清除历史会重新签到吗？

不会。按钮删除本机显示的历史，学校记录和当天提交保护仍保留。后台之后发生的新任务会产生新历史，记录页的只读刷新不会补回已清除的历史。

## 升级提示应用未安装或签名不兼容？

确认包名和签名与已安装版本一致。不要直接卸载旧版：卸载会丢失本机密钥、设置和登录。请将版本号及错误提示反馈给维护者，不要提供密码、Cookie 或个人配置。

## 登录页面自动进入，是否正常？

已有有效会话时可以自动进入。应用内 WebView 与其他手机浏览器的登录资料独立，以应用内状态和学校保存的记录为准。

## 加密数据可以跨设备复制吗？

Android 密钥绑定应用安装与设备，Windows 密钥绑定当前系统用户。不要删除 .goodnight-key 或尝试把浏览器资料和加密状态直接迁移给别人。复制手机配置仅传递设置，不传递学校登录凭证。
