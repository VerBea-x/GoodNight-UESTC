# GoodNight v0.6.6｜Android 预发布

本版本主要修复自动签到开关及顶部状态刷新时的卡顿。已完成 APK 构建、内嵌版本核对与签名校验；真实手机的动画、后台唤醒及通知到达仍需验证，因此作为预发布提供。

## 本次更新

- 顶部在点击时立即显示正在开启或关闭，完成保存后再显示确认状态。
- 状态解密、计划保存和系统任务注册放到后台线程。
- 连续点击以最后一次选择为准，过期状态回调不会覆盖新选择。
- 支持本机历史清除、浅灰按钮及通知状态提示。

## 下载与升级

下载附件 GoodNight-Android-v0.6.6.apk，Android 8.0 或以上可安装。Source code 是源码，不是手机安装包。

当前为调试签名测试包。请先覆盖安装以保留设置和学校会话；如提示签名不兼容，请保留旧应用并反馈，勿直接卸载。配置文字不含登录凭证；卸载可能丢失本机加密数据。

## 使用

学校登录 → 粘贴配置或填写坐标与时间 → 开启自动签到 → 查看通知并核对学校记录。Android 13 及以上需允许通知，同时检查系统后台限制。自动任务可能受网络、登录和省电影响，无法承诺准点。
